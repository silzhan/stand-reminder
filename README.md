# 起身助手

一个常驻 Windows 桌面的久坐提醒工具：按固定节奏提示你改变姿势、起身活动，并提供简短的腰椎友好提示。

> 本应用只是提醒工具，不是医疗设备，内容不构成医疗建议。若出现持续疼痛、腿部麻木或无力加重，请停止活动并咨询医生。

## 功能

- **可配置节奏**：默认工作日 09:00–18:00，午休 12:00–13:30 暂停；默认 45 分钟坐姿 + 5 分钟起身，时间表、午休和时长均可调整。
- **不易错过但不打断**：置顶提醒弹窗 + 柔和提示音，支持“已起身并休息”“稍后 5 分钟”“稍后 10 分钟”；未处理 60/120 秒后提高视觉等级并再次响铃，不做全屏强制遮挡。
- **四种显示形态**：仅托盘、置顶小挂件、悬浮球、桌面看板，可随时切换，并记住窗口位置与显示器变化。
- **托盘常驻**：单击托盘打开看板；可暂停 30 分钟、1 小时或今天；关闭窗口只隐藏，从托盘菜单退出。
- **系统行为**：单实例；锁屏/休眠期间暂停并冻结计时；打包安装版默认开机自启；启动时不抢占焦点。
- **本地统计**：记录坐姿时长、提醒次数、延后次数、起身开始/完成情况，看板展示本周概览，数据保留 30 天。
- **纯本地**：无账号、无云同步、无网络请求。

## 系统要求

- Windows 10/11 x64
- 开发与构建需要 Node.js 22 LTS 或更高版本

## 开发运行

```bash
npm install
npm start
```

国内网络下载 Electron 较慢时，可在 Git Bash 中设置镜像：

```bash
ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/" npm install
```

## 构建安装包

```bash
npm run dist
```

产物为 `dist/StandReminder-Setup-0.1.0.exe`，按用户安装，无需管理员权限。安装包未签名，首次运行会触发 Windows SmartScreen 提示。

## 测试

```bash
npm test       # 50 项调度、统计、存储单元测试
npm run smoke  # 启动隔离的 Electron 实例进行 UI 冒烟与截图
```

冒烟测试使用临时数据目录和加速节奏，截图输出到 `artifacts/smoke/`。

## 数据与隐私

设置和统计保存在：

```text
%APPDATA%\StandReminder\store.json
```

写入采用临时文件 + 原子替换；文件损坏时自动备份为 `.bad` 并恢复默认值。统计仅保留最近 30 天。所有数据只在本机，不联网。

卸载程序会移除应用写入的开机自启项，但不会自动删除上述数据文件；如需彻底清理，可手动删除 `%APPDATA%\StandReminder`。

## 项目结构

```text
src/main/      主进程、调度、窗口、托盘、提醒与持久化
src/preload/   contextBridge 白名单 API
src/renderer/  小挂件/悬浮球、看板与提醒页面
src/shared/    时间表、状态机、统计与提示文案
test/          Node 单元测试
scripts/       图标生成与 Electron 冒烟脚本
build/         图标、安装器脚本等构建资源
```

## 已知限制

- 未签名安装包会触发 SmartScreen；项目不包含代码签名证书。
- 独占全屏程序之上无法保证提醒弹窗可见。
- 不识别法定节假日；临时休息日可使用“暂停今天”。
- 应用退出后不会恢复退出前的计时，下次启动会开始新的完整坐姿周期。
- 开发模式下不会注册开机自启，只有打包安装版才会启用。
